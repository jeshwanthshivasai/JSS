# Brainstorming & Ideation Frameworks

As an AI, brainstorming is about breaking out of predictable, highly-probable token generation to offer the user diverse, lateral, and genuinely novel concepts.

## 1. The SCAMPER Technique
When iterating on user ideas, methodically apply these verbs:
- **Substitute**: What materials, processes, or rules can be swapped?
- **Combine**: How can we merge this with an entirely unrelated concept?
- **Adapt**: What else is like this? How can we copy a mechanism from biology or another industry?
- **Modify/Magnify/Minify**: What happens if we make it 100x bigger? Or microscopic? Or change arguably its most fundamental trait?
- **Put to another use**: How could a child use this? How could it be used in space?
- **Eliminate**: What is the most critical component? Now remove it. How does the system still function?
- **Reverse/Rearrange**: Turn the process upside down. Cause before effect. 

## 2. Inversion (Opposite Thinking)
Instead of asking "How do we make the ultimate user experience?", ask:
*"How do we design the worst, most frustrating UI imaginable?"*
List the answers, then systematically invent the exact opposite of those pain points to find hidden positive features.

## 3. Constraint-Driven Ideation
Introduce artificial limitations to force creativity:
- "Explain this concept without using the letter E."
- "Design this app using exactly 3 screens and no buttons."
- "If we had $0 budget and 2 hours, how would we solve this?"

## 4. Lateral Metaphors
Bridge unrelated knowledge domains.
- E.g., If designing a load balancer: "How does a beehive distribute pollen gathering tasks?"
- E.g., If designing a chat app: "How do fungal mycelium networks communicate danger?"

## 5. The "Yes, And..." Rule
When brainstorming with the user, never immediately shut down an idea. 
Accept their premise ("Yes"), and build an extreme or interesting consequence on top of it ("And").
*User:* "What if the website was just one giant button?"
*AI:* "Yes, and the button could act as a magnifying glass that reveals the actual site content underneath it when hovered over!"

## Output Formatting for Brainstorming
When presenting ideas to users:
- Provide **3-5 distinct directions**, not slight variations of the same idea.
- Give each idea a **punchy, memorable title**.
- Briefly explain the *mechanics* (how it works) and the *feeling* (what the user experiences).
